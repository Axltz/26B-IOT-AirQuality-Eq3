# 26B-IOT-AirQuality-Eq3
Sistema IoT para el monitoreo de la calidad del aire en exteriores y confort ambiental. Diseñado conceptualmente como una propuesta comunitaria para la gestión de alertas mediante un semáforo visual y notificaciones push. Proyecto escolar para la materia de Internet de las Cosas (26B) - CUCEI.
